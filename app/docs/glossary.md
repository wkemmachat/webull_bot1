# Glossary (EN / ไทย)

| English | ไทย | Meaning |
|---|---|---|
| Strategy | กลยุทธ์ | A rule set with its own money and books |
| Target | เป้าหมายการถือ | What share of its money a strategy wants in each ETF |
| Plan | แผนคำสั่ง | The split orders that move a strategy to its target |
| Lot / round | ล็อต / รอบ | One small limit order / one step of a plan |
| Allocated to the bot | เงินที่มอบให้บอท | Strategies + bot unassigned; the only money the bot uses |
| Bot unassigned | เงินของบอทที่ยังไม่ได้แบ่ง | Given to the bot, not yet to a strategy |
| Not for the bot | เงินที่บอทไม่แตะ | Cash you did not allocate, plus your own shares |
| Regime | สภาวะตลาด | 2x, 1x, 0.5x or off, read from QQQ or SMH |
| Supertrend | ซูเปอร์เทรนด์ | Trend line from ATR; a 4H close below it ends a long |
| ADX | เอดีเอ็กซ์ | Trend strength; Gold #1 buys only above 20 |
| Donchian | ดอนเชียน | Highest high / lowest low of the last N bars |
| Paper | เทรดจำลอง | Pretend money inside the bot |
| Digest | สรุปรวม | LINE messages collected and sent at set times |
